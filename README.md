# persona_generator

[`prompt-composer-static`](https://github.com/sgktmr808/prompt-composer-static) が書き出した生成プロンプト+設定値をまとめて貼り付け、1件ずつ本文と設定を取り出し、生成画像をレビューするiPhone向け関連UI。

生成ルール、キーワードDB、重み、プロンプト生成処理などの本体機能は `prompt-composer-static` 側だけが所有します。このリポジトリは `PCEXPORT` の出力を受け取るUIであり、本体アルゴリズムを含みません。

ビルドステップ無し・依存無し・単一の `index.html` のみ。サーバーサイド処理は無く、貼り付けた内容はブラウザの `localStorage` にのみ保存され、どこにも送信されません。

## 使い方

1. プロンプト生成側アプリで「全件+設定をコピー」ボタンを押す(`<<<PCEXPORT v1 count=N>>>` 形式のテキストがクリップボードにコピーされる)。
2. このツールを開き、貼り付け欄にペーストして「解析する」を押す。ペーストの代わりに「ファイルを開く」から `.md`/`.txt` ファイルを選んで読み込むこともできる(端末内で読み込むだけで、どこにもアップロードされない)。
3. 「前へ」「次へ」(またはスワイプ)で1件ずつ移動し、「本文をコピー」「設定をコピー」でそれぞれ個別にコピーできる。
4. 「画像レビュー」で表示中のプロンプトに生成画像を登録し、採否・美的満足度・意図一致度をタップして「保存して次へ」を押す。プロンプト本文・設定・Seedは自動で紐付き、記録はJSONLで書き出せる。画像はまとめて選択し、選択順に各プロンプトへ割り当てることもできる。

前回貼り付けた内容とレビュー結果は端末内に保存され、再度開いたときに自動で復元されます。生成画像は一時プレビューだけで保存されません。

## フォーマット

```
<<<PCEXPORT v1 count=N>>>
<<<PROMPT 01>>>
(プロンプト本文、複数行可)
<<<SETTINGS 01>>>
(1行のJSON設定値)
<<<PROMPT 02>>>
...
<<<PCEXPORT END>>>
```

## ローカル確認

```bash
python3 -m http.server 8090
```

`http://localhost:8090/` を開く。
