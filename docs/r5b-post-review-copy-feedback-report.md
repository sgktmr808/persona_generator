# R5Bレビュー後：本文コピーフィードバック改善記録

日付: 2026-08-23  
対象: 公開A/BレビューUIのガイド生成画面

## 目的

「この本文をコピー」を押した直後、iPhoneの長い画面でも利用者が視線を移動せずに、コピーの成功・失敗を判別できるようにする。

## 原因

共通のコピーボタン状態表示は既に存在していたが、ガイド生成画面の主要ボタンはその処理へ接続されていなかった。既存検査も画面下部の案内文だけを確認し、押したボタン自身の見え方を確認していなかった。

## 変更

- 処理中は押したボタンを琥珀色の「コピー中…」にする。
- 成功時は同じボタンを緑色の「✓ コピーしました」にし、2.8秒保持する。
- 失敗時は同じボタンを赤色の「コピーできません・再試行」にする。
- 自動コピー失敗時の読み取り専用本文欄と全選択の救済経路は維持する。
- 強い表示と2.8秒保持はガイド生成画面だけに限定し、比較画面の既存コピーボタンには波及させない。

## 受入結果

- iPhone幅 320 / 375 / 390 / 430px、および横向き844×390で横溢れ0px、文字サイズ16px以上。
- 390px幅で成功・失敗状態を実画面撮影して目視確認。
- 成功表示が1秒後も残ること、成功時に背景色・強調枠・文字が同時に変わることを自動検査。
- Clipboard API成功・不在・拒否の全経路を検査。
- A/BレビューUI全リリースゲート: 11 / 11 PASS、再試行0、残存プロセス0、Downloadsへの検査成果物流出0。

この記録には実験パッケージ、プロンプト本文、画像、レビュー値を含めない。
